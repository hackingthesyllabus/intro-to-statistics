About these problems. All data are hypothetical. Final answers are rounded to 2 significant figures, the course rule (syllabus, “Rounding”). Working steps keep more digits so that rounding does not build up. Critical values come from the t table at the df shown; if your df is not listed, use the next row down, which is the more conservative choice. Two-sample problems use the Welch method, the same one the decision tree uses. If your instructor uses the pooled-variance formula, the t values will differ.
